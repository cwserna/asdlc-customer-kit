## 2. Quickstart: New Project, Joining an Existing Team Project, or Upgrading

> **Workstation Safety & Toolkit Dependencies:** Run A/SDLC only on a corporate IT / non-production workstation (never inside an OT/SCADA Electronic Security Perimeter or jump host). Installing this Pure Markdown toolkit requires **zero Python dependencies** (install Python 3.12+ only if your target application itself uses Python). Always check `~/.gemini/config/` before copying so you do not overwrite existing organization skills of the same name.

### Option A: Fresh Installation (Starting a New Project)
Clone the pinned `v3.1.1` release tag (or unzip [`v3.1.1.zip`](https://github.com/cwserna/asdlc-customer-kit/archive/refs/tags/v3.1.1.zip), which extracts to `asdlc-customer-kit-3.1.1/`), copy `agents/*.md` and `skills/*` into `~/.gemini/config/` (global) or `.agent/` (workspace-only), restart Antigravity (or start a brand-new chat), and run:
1. `/asdlc-onboarding-coach` to verify your Google Cloud, Git/GitHub, and OpenTelemetry readiness.
2. `/org-standards-builder` (optional, before or during Stage 1) to distill internal wiki standards into a `<= 120` line `org-standards.md` and `.okf/runbooks/` catalog using an enterprise-approved ZDR AI surface.
3. `/agentic-sdlc --new` to launch Stage 1 Project Onboarding.

### Option B: Joining an Existing Team Project (New Developer Starting from Zero)
If your team already has an active A/SDLC project repository and this is your first time setting up A/SDLC on your workstation:
1. **Confirm access, OT isolation, & sign in:** Confirm your workstation is on a non-production IT network, confirm your Gemini Enterprise seat, your 4 developer Google Cloud IAM roles (`roles/discoveryengine.agentspaceUser`, `roles/aiplatform.user`, `roles/cloudaicompanion.user`, `roles/serviceusage.serviceUsageConsumer`), and your **accepted** GitHub repository collaborator invite (plus GitHub Org SAML Single Sign-On (SSO) authorization if required). Configure Git (`git config --global user.name` / `user.email`), sign in to GitHub (`gh auth login && gh auth setup-git`), bind a dedicated `gcloud` configuration (`gcloud auth login`, `gcloud config set project <PILOT_PROJECT_ID>`, `gcloud auth application-default login`, `gcloud auth application-default set-quota-project <PILOT_PROJECT_ID>`), and sign in to Google Antigravity 2.0 via **Use business account** matching your project's pinned data-residency region (`Global`, `US`, or `EU`) (never **Continue with Google**).
2. **Install this pinned `v3.1.1` toolkit globally & restart Antigravity:** Keep `asdlc-customer-kit` in `~/Downloads/asdlc-customer-kit` (separate from your app repo). Copy `agents/*.md` and `skills/*` into `~/.gemini/config/` (macOS/Linux: `mkdir -p ~/.gemini/config/agents ~/.gemini/config/skills && cp -R ~/Downloads/asdlc-customer-kit/agents/*.md ~/.gemini/config/agents/ && cp -R ~/Downloads/asdlc-customer-kit/skills/* ~/.gemini/config/skills/`; Windows PowerShell: `New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.gemini\config\agents","$env:USERPROFILE\.gemini\config\skills"; Copy-Item -Recurse -Force "$HOME\Downloads\asdlc-customer-kit\agents\*.md" "$env:USERPROFILE\.gemini\config\agents\"; Copy-Item -Recurse -Force "$HOME\Downloads\asdlc-customer-kit\skills\*" "$env:USERPROFILE\.gemini\config\skills\"`). Fully quit and reopen Antigravity (macOS `Cmd+Q` / Windows tray Quit) so the skills load. *(If your team commits `.agent/` inside the app repo, confirm with your Project Lead whether repo `.agent/` takes precedence over `~/.gemini/config/`.)*
3. **Clone your team's app repo into a separate folder, review repo configs, and resume (never `--new`):**
   ```bash
   # macOS / Linux (Windows PowerShell: New-Item -ItemType Directory -Force -Path "$HOME\projects"; Set-Location "$HOME\projects")
   mkdir -p ~/projects && cd ~/projects
   git clone <PROJECT_GIT_REPO_URL> <PROJECT_FOLDER>
   cd <PROJECT_FOLDER>
   # If joining mid-stage, check out the active stage branch: git checkout <ACTIVE_BRANCH>
   ```
   Review `.sdlc/toolchain_config.json`, `.sdlc/remote.json` (if present), and any repo `.agent/` files with your Project Lead, then open `~/projects/<PROJECT_FOLDER>` in Antigravity, start a new chat, and run `/agentic-sdlc --resume .`, followed by `/agentic-sdlc --status`, `/agentic-sdlc --git-status`, and `/agentic-sdlc --toolchain-status` (see Section `5.6` of [`ASDLC_OPERATOR_RUNBOOK.md`](./ASDLC_OPERATOR_RUNBOOK.md) for the complete macOS/Linux/Windows/Proxy walkthrough and teammate offboarding checklist).

### Option C: Fast-Track Zero-Rework Upgrade from `v3.0` (Teams in Stage 1) or Smart 3-Way Upgrade from `v1.0`/`v2.x`
If you already have `A/SDLC v3.0` (or `v1.0`/`v2.x`) installed, review **[`UPGRADE.md`](./UPGRADE.md)** first (Section 0 covers the 2-minute zero-rework Stage 1 upgrade that preserves 100% of your `RACI.md`, `.sdlc/git_config.json`, `org-standards.md`, `.okf/intake/`, and signed Gate 1 receipts). Download the pinned **[`v3.1.1` ZIP](https://github.com/cwserna/asdlc-customer-kit/archive/refs/tags/v3.1.1.zip)** or run `git clone --branch v3.1.1 --depth 1 https://github.com/cwserna/asdlc-customer-kit.git` into `~/Downloads`, **inspect `UPGRADE.md` before running**, open your AI chat inside that downloaded folder, and paste:
```text
Read ./UPGRADE.md and ./skills/agentic-sdlc/SKILL.md in this v3.1.1 repository and execute the Smart 3-Way Agent & Workspace Upgrade against my installed ~/.gemini/config/ (or .agent/) definitions and my active A/SDLC project workspaces.
```
After Step 1 finishes updating your installed files, **fully restart Antigravity (or start a brand-new chat session)** so the `v3.1.1` definitions load into memory.
